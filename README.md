# Recruitment Pipeline

지원자를 채용 단계별로 관리하는 React 기반 채용 파이프라인 보드입니다.

지원자 검색과 직무 필터, 드래그 앤 드롭 단계 이동, 낙관적 업데이트와 실패 복구, 지원자 상세 보기를 지원합니다. Mock API와 localStorage를 사용해 변경된 지원자 데이터를 브라우저에 저장합니다.

## 실행 방법

```bash
npm install
npm run dev
```

터미널에 표시된 로컬 주소로 접속합니다.
